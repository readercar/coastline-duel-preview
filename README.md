# COASTLINE / DUEL

Cocos Creator 3.8.8 racing prototype.

Play: https://readercar.github.io/coastline-duel-preview/

Landscape view. Left-side drag steers; hold the right side to accelerate, drag downward to brake. Keyboard: WASD / arrows; Space brakes.

This static preview supports a 1:1 race against the computer. Live player matchmaking and private rooms require a separate WebSocket server and are unavailable in this shared build.
