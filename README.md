# Ember Ascent

Cocos Creator 3.8.8 / TypeScript로 만든 세로형 레트로 방치형 RPG 개발 빌드입니다. 사용자 제공 TT2 역기획서의 전투와 성장 구조를 독립 구현합니다. **원작의 100% 복제 또는 202개 화면 완성본이 아닙니다.**

## 실행

- Cocos Creator 프로젝트: 이 저장소의 루트
- 시작 씬: `assets/scenes/Main.scene`
- 웹 빌드 설정: `config/build-web.json`
- 웹 산출물: `build/web-mobile/index.html`
- 개발 서버와 웹 주소: `http://127.0.0.1:8788`

이 컴퓨터에서는 다음 런타임으로 검증했습니다.

```sh
/Users/dhlee/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node scripts/test.cjs
/Users/dhlee/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node scripts/build.cjs
/Users/dhlee/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node scripts/server.cjs
```

Node 22.13 이상 환경에서는 `npm test`, `npm run build`, `npm run server`도 사용할 수 있습니다. Cocos CLI 경로와 Node 타입 선언 경로는 현재 Mac의 설치 위치로 설정되어 있습니다. 다른 컴퓨터에서는 `scripts/`의 경로를 해당 설치에 맞춰 변경해야 합니다. 별도 npm 패키지 설치 없이 현재 컴퓨터의 Cocos TypeScript 컴파일러와 제공 런타임을 사용합니다.

## 플레이

전투 필드를 탭해 공격하고 수호자와 동료를 강화합니다. 적 5마리를 처치하면 30초 제한의 보스전에 진입합니다. 보스 실패 후에는 일반 적을 사냥하거나 보스에 다시 도전할 수 있습니다. 구역 8에서 정령, 15부터 장비, 60에서 환생을 이용합니다. 탭과 팝업을 열어도 메인 전투는 계속됩니다.

6개 하단 탭은 수호자·동료·장비·정령·유물·상점입니다. 상단 메뉴에서 일일 임무·업적·이정표·솔로 레이드·카드·이벤트·심화 성장·길드·대회를 엽니다. 설정에서 한국어/영어와 효과음을 변경합니다. 모든 팝업은 원래 화면 위 검정 알파 128/255 딤과 여백 있는 패널입니다.

주문은 10종 중 6개를 선택합니다. 500레벨부터 활성 주문 중첩이 가능합니다. 유물은 발견·강화·분해·복구·각성을 지원하며, 장비는 잠금·장착·판매·일괄 판매·세트 제작을 제공합니다.

## 데이터와 서비스 경계

메인 원정은 브라우저의 `ember-ascent-v1` 로컬 저장입니다. 5초 주기로 저장하며 영구 재화 변이는 저장 성공 후 확정합니다. 읽을 수 없는 저장은 `ember-ascent-corrupt-<timestamp>` 키로 보존한 뒤 새 저장을 만듭니다. 구형 저장의 새 필드는 마이그레이션합니다. 비접속 보상은 최대 8시간입니다.

길드와 개발 대회는 Node HTTP 서버 및 `.local-server/development.sqlite`에 저장합니다. 계정 토큰은 브라우저 로컬 저장에 있으며 로그나 저장소에 기록하지 않습니다. 서버는 `127.0.0.1`에만 바인딩합니다. 서버 중지 후에도 DB 파일은 유지됩니다. 브라우저 저장을 삭제하면 익명 계정의 토큰을 잃으며 계정 복구·이메일 연결은 구현하지 않았습니다.

개발 서버는 길드 생성·가입·채팅·길드장 위임·탈퇴와 공동 보스 HP를 실제 처리합니다. 공동 레이드는 12시간마다 3회, 30초 동안 8부위에 공격하는 서버 계산 전투입니다. 덱의 발동, 공격 간격, 결과 제출과 재접속을 서버가 검증합니다. 길드전 카드는 공용 1레벨이며 로컬 카드 강화는 솔로 레이드에 적용됩니다. 독립 대회는 하루 단위이며 서버가 전투와 순위를 계산합니다. 원작의 정규 토너먼트 매칭이나 주간 AT와 동일하지 않습니다.

서버 대회 보상은 서버에서 한 번 확정하고 로컬 메인 저장에 한 번 반영합니다. 메인 재화 전체가 권위 서버로 이전된 구조는 아니므로 운영 경제·치팅 방지·기기 간 동기화가 완성되었다고 볼 수 없습니다.

## 검증과 남은 범위

`docs/IMPLEMENTATION_REVIEW.md`에 원본 문서 평가, 구현 범위, 검증 결과와 주요 차이를 기록했습니다. `docs/screen-coverage.json`은 문서의 202개 ID를 누락 없이 보존합니다. 각 ID의 상태와 남은 QA 경로를 명시하며, 목록이 존재하는 것 자체를 구현 완료로 계산하지 않습니다.

콘텐츠 수량과 모든 성장 수치는 독립 개발용입니다. 현재 동료 24, 정령 12, 유물 30, 특성 노드 18, 레이드 카드 18, 영혼 인덱스 120, 보석 24를 사용합니다. 영혼 120종은 고유 개별 연출·상세 스탯이 모두 구현된 것이 아닙니다. 실제 과금·광고·모바일 푸시와 운영 서버는 연결하지 않았습니다. 시즌 리셋·우편, 연금술·구슬 낙하·탑·공동 토벌을 독립 규칙으로 구현했으며 원작 전체 규칙과는 차이가 있습니다. 모바일 스토어 등록이나 배포는 수행하지 않았습니다.

회사 CI는 지정 원본 `tt-softs-ci.png`를 그대로 복사해 설정에 표시합니다. 캐릭터와 배경은 Cocos Graphics 기반의 독립 도형이며 원본 게임 이미지나 스크린샷을 게임 자산으로 사용하지 않습니다.

## 2026-10-02 추가 구현

전투 구도를 중앙의 거대 괴수 정면과 아래쪽 주인공 뒷모습으로 수정했습니다. 공격 시 검 궤적·주인공 동작과 피격 효과가 재생됩니다. 구역에 따라 괴수 팔레트가 바뀝니다.

상단 메뉴의 **성장과 축제**에서 축복 교체, 빌드 개요, 동료 승천·스킬, 정령 짝 맞추기·이정표, 정수 상점·카드 공명, 배너·10회 소환·영혼 일괄 강화, 보석 연구·마일스톤, 기념비 분해·각성·시즌 우편, 일일 수집, 우편 수령·삭제, 외형, 저장 내보내기, 축제 변형을 엽니다. 동료/정령 목록 왼쪽 상세 영역에서도 각각 상세 화면에 진입합니다.

길드의 ⋯ 메뉴에서 검색·편집·스티커·기여 기록·금고·토벌 재시작을 사용합니다. 독립 대회 상점은 대회 재화만 소비합니다. 공동 토벌은 일일 서버 HP와 기여 순위를 사용합니다. `EMBER_MAINTENANCE=1`로 서버를 시작하면 상태 조회를 제외한 API를 점검 상태로 차단하며 로컬 원정은 유지됩니다.

브라우저 알림은 사용자가 권한을 허용하고 게임 탭이 백그라운드에서 실행 중일 때 알·일일 보상·우편에 대해 동작합니다. 탭이 닫힌 상태의 푸시는 지원하지 않습니다.

추가 검증: `scripts/expansion-visual-test.cjs`(31개 확장 화면 × 한국어/영어), `scripts/extended-online-test.cjs`(길드 부위 전투·중단/복귀·결과, 공동 토벌, 길드 도구). 검증은 임시 계정으로 수행하고 해당 계정만 삭제합니다.

- 솔로 레이드 포털 선택/덱 프리셋/일일 보상, 재접속 복구 및 원자적 보상 수령

### 광고·유료 상품

상점의 다이아몬드 상점에서 한국 iOS 참조 가격과 구매 확인을 제공합니다. 요정, 메가 부스트, 영상 상자에 선택형 광고 진입점과 보상·횟수 제한을 연결했습니다. 구매/광고 검증 인터페이스, 중복 방지 지급 원장, 복원/재시도를 추가했습니다. 실제 결제·광고 SDK는 미연결이며 성공으로 처리하지 않습니다. 근거별 수치와 미확정 번들/패스 범위는 `docs/IMPLEMENTATION_REVIEW.md` 마지막 절을 참고하세요. 검증: 코어 56개 + 서버 20개, Cocos 웹 빌드 통과.
