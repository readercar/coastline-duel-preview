TT Softs · 계정 및 관련 데이터 삭제 요청

게임의 설정 → 계정 → 계정 및 데이터 삭제 요청에서도 이 안내를 열 수 있습니다.

  1. 아래 버튼으로 admin.ttsoft@gmail.com에 삭제 요청을 작성하세요.
  2. 게임의 계정 화면에 표시되는 계정 ID와 부대명을 적어 주세요. Google 로그인 계정은 연결된 이메일에서 요청하면 본인 확인에 도움이 됩니다.
  3. 접근할 수 없는 계정이라면 그 사실을 알려 주세요. 본인 확인 방법과 처리 일정을 회신합니다. 확인 후 계정과 관련 클라우드 데이터를 삭제합니다.

이메일로 삭제 요청 시작

계정·로그인 연결, 클라우드 진행, 부대명, 재화·아이템·해금, 알림 및 우편 수령 기록이 삭제 대상입니다. 삭제한 진행은 복구할 수 없습니다. 비밀번호, 인증 코드, 결제 카드 정보는 보내지 마세요. 앱을 지우는 것만으로 서버 계정은 삭제되지 않습니다.

법률상 의무, 부정 결제 방지 또는 결제 분쟁에 필요한 최소 거래·보안 기록은 해당 목적에 필요한 기간 별도로 보관할 수 있습니다. 해당 기록과 보관 사유는 요청 처리 시 안내합니다. 구매 환불은 Google Play의 환불 절차에 따르며 계정 삭제 자체가 환불을 처리하지 않습니다.

Request account and associated data deletion

You can also open this guide from Settings → Account → Request account and data deletion in the game.

  1. Email admin.ttsoft@gmail.com using the button below.
  2. Include the account ID shown in the game and your squad name. For Google sign-in, contacting us from the linked email helps verify ownership.
  3. If you cannot access the account, explain this in your request. We reply with verification steps and a processing schedule. After verification, we delete the account and associated cloud data.

Start a deletion request by email

Deletion covers the account and login links, cloud progress, squad name, currency, items, unlocks, and notice and mail claim records. Deleted progress cannot be recovered. Never send passwords, verification codes or card details. Uninstalling the app does not delete its server account.

Minimum transaction and security records required by law, payment fraud prevention or a dispute may be retained separately for the necessary period. We explain any retained records and the reason when handling the request. Refunds follow Google Play's refund process; account deletion does not itself issue a refund.
